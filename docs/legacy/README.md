# Описания удалённых Тильда-скриптов

Эта папка — наша "память" о том, что делали скрипты и стили, которые мы удалили из проекта в ходе миграции с Тильды.

## Зачем

Тильда поставляет много готовых скриптов: калькулятор, аккордеоны, слайдеры, попапы, формы, анимации. Когда мы их удаляем, важно сохранить понимание:

- что они делали;
- какие функции были внутри;
- какие визуальные эффекты обеспечивали;
- где использовались.

Это нужно, чтобы:

1. **Гарантировать, что мы ничего не потеряли.** Если в новом коде какой-то функции не хватает — мы знаем, где искать.
2. **Иметь подсказку для нейросети.** При написании Astro-аналога нейросеть может опираться на это описание.
3. **На случай отладки.** Если что-то не работает — можно сравнить ожидаемое поведение с этим описанием.

## Когда заполняется файл

**Перед** удалением каждого Тильда-скрипта или стиля. Последовательность:

1. Открываешь Тильда-файл (например, `public/js/tilda-calc-1.0.min.js`).
2. Создаёшь `docs/legacy/tilda-calc-1.0.min.js.md`.
3. Описываешь его (см. шаблон ниже).
4. **Только после этого** удаляешь оригинальный файл.

Это правило закреплено в `.cursor/rules/tilda-migration.mdc` и применяется ко всему `tilda-*` и `fonts-tildasans.css`.

## Шаблон файла

Файл называется по имени оригинала: `<оригинальное-имя-файла>.md` (например, `tilda-calc-1.0.min.js.md`).

Содержимое (это шаблон — копировать целиком, заполнять под конкретный скрипт):

```markdown
# tilda-calc-1.0.min.js

**Оригинальный путь:** `public/js/tilda-calc-1.0.min.js`
**Дата удаления:** 2026-MM-DD
**Размер:** XX KB

## Что делал

Краткое описание в 2-3 предложениях.

## Где использовался

- `public/calculator.html` (главное место)
- `public/order.html` (упрощённая версия)
- ... (другие страницы, если есть)

## Ключевые функции и селекторы

Список функций / классов, которые экспортировал скрипт, и что они делали:

- `t_calcInit(formId)` — инициализирует калькулятор по id формы.
- `t_calcCalculatePrice()` — пересчитывает цену по выбранным опциям.
- `t_calcFormatPrice(price)` — форматирует число в "55 BYN".

## Зависимости

От каких других файлов или библиотек зависел:

- Опирается на jQuery 3.x (загружается в общем `tilda-scripts-3.0.min.js`).
- Использует CSS-классы из `tilda-calc-1.0.min.css`.

## Новый Astro-аналог

Где живёт замена:

- `src/scripts/calculator.js` — переписан с нуля на vanilla JS.

Или, если функциональность не нужна:

- `не требуется` — функциональность убрана / неактуальна на новом сайте.

## Примечания

Особенности поведения, edge cases, ловушки, на которые нужно обратить внимание при написании аналога.
```

## Принципы заполнения

- **Пишем на русском.**
- Описание должно быть достаточно подробным, чтобы по нему можно было заново реализовать функциональность через 3 месяца, не глядя в оригинал.
- Если скрипт миниатюрный и очевидный (например, IIFE из трёх строк) — можно ограничиться кратким описанием в 2–3 строки.
- Если скрипт сложный (калькулятор) — описание может занимать несколько страниц.
- Названия функций / селекторов **цитируем как есть** в оригинале, чтобы при отладке можно было сопоставить.

## Файлы, которые точно сюда попадут

По мере миграции в этой папке появятся файлы для (приблизительный список — точный список появится во время инвентаризации в фазе 1–2):

- `tilda-calc-1.0.min.js.md` — **калькулятор стоимости. САМЫЙ ВАЖНЫЙ.**
- `tilda-animation-2.0.min.js.md` — анимации появления элементов.
- `tilda-animation-sbs-1.0.min.js.md` — пошаговые анимации.
- `tilda-blocks-*.js.md` — отдельные тильдовские блоки по каждой странице.
- `tilda-buyer-dashboard-1.0.min.js.md` — личный кабинет покупателя (если используется).
- `tilda-cards-1.0.min.js.md` — карточки услуг.
- `tilda-date-picker-1.0.min.js.md` — выбор даты в формах.
- `tilda-events-1.0.min.js.md` — общая система событий.
- `tilda-forms-1.0.min.js.md` — обработка форм.

- `tilda-scripts-3.0.min.js.md` — базовая библиотека.
- `tilda-slds-1.4.min.js.md` — слайдеры.

### CSS

- `tilda-blocks-*.min.css.md` — стили блоков по страницам.
- `tilda-animation-2.0.min.css.md` — стили анимаций.
- `tilda-grid-3.0.min.css.md` — система гридов.
- `fonts-tildasans.css.md` — описание подключения шрифта TildaSans (заменён на Onest).

## Что НЕ нужно сюда класть

- Тривиальные inline-скрипты из HTML (аналитика, пиксели).
- Файлы с явно собственными названиями, не помеченные как Тильда (например, наш собственный `home.js` если в нём нет копирайта Тильды).
- Изображения — они переименовываются, но не удаляются. Это не "удалённый Тильда-объект".
