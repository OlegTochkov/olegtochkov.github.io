# Визуальная идентичность — Clean Logic

Документ описывает характер бренда и цветовую систему. Технические детали (размеры, отступы) — в соседних файлах.

## Характер бренда

- **Дружелюбный и массовый.** Не премиум, не сухой «банк», не уютная «соседка». Доступный, понятный сервис для обычных людей.
- **Эмоции, которые должен вызывать сайт:** уверенность, доступность, простота, спокойствие.
- **Декоративность — лёгкая.** Не голый минимализм, но и не перегруженный декор. Чистая база + аккуратные акценты.
- **Целевая аудитория** (см. `docs/marketing/audience.md`): преимущественно женщины 25–34 и 55+, заходят с телефона. Значит, дизайн — mobile-first, крупные кликабельные зоны, понятные подписи.

## Политика градиентов

Это важное правило (см. также [`do-and-dont.md`](do-and-dont.md)).

**Разрешены** только фирменные функциональные градиенты:

- `--grad-btn` — `linear-gradient(3.4deg, rgba(134,223,242,1) 0%, rgba(82,125,222,1) 100%)` — для главных CTA-кнопок.
- `--grad-price` — `linear-gradient(3.4deg, rgba(79,213,241,1) 0%, rgba(35,91,218,1) 100%)` — для блока цены.

**Запрещены:**

- Декоративные градиенты на фоны секций.
- Фиолетово-розовые / неоновые градиенты «нейросетевого» вида (анти-референс Neuro 2 — см. `anti-references/external-sites.md`).
- Любые градиенты «для красоты», не несущие функции.

Принцип: градиент — это фирменный приём ровно для двух вещей (кнопка действия и ценник). Везде ещё — плоские цвета.

## Фотографии, иконки, иллюстрации

Приоритет визуальных элементов (по словам владельца):

1. **Фотографии** — главное. Реальные снимки уборки, обязательно с людьми (сотрудницами). Это доказательство и доверие. Подтверждено тестом: фото с человеком повышает CTR (см. `docs/marketing/experiments.md`).
2. **Текст** — заголовки, цены, короткие описания.
3. **Иллюстрации** — только векторная графика в фирменной палитре (синий/голубой). Без растровых «артов».
4. **Иконки** — для категорий услуг (химчистка ковров, матрасов и т.п.). Один стиль, фирменная палитра, плоские. Не чёрные, не разнокалиберные (анти-пример Tidy — см. `anti-references` и `good-bad/bad-sites/`).

Запреты:

- Никаких стоковых «деловых людей в офисе».
- Никаких сгенерированных нейросетью «digital art» изображений.
- Никакой космической / абстрактной стилистики.

## Тень и глубина

Одна базовая тень для карточек: `--shadow-card` = `0 0 15px rgba(0,0,0,0.08)`. Мягкая, ненавязчивая. Не плодить разные тени.
