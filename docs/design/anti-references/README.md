# Папка anti-references — текстовые материалы анти-референсов

Здесь собраны текстовые источники, формулирующие принципы «как не надо делать дизайн». В отличие от соседней папки `../good-bad/`, тут не скриншоты, а правила и выводы — извлечённые из видео-разборов и наблюдений за конкретными плохими сайтами.

Все материалы — **исходники** для будущей дизайн-документации. Финальный документ `docs/design/do-and-dont.md` будет собран позже на этапе реализации.

## Состав папки

- [`video-lessons.md`](video-lessons.md) — выжимка анти-правил из трёх видео-разборов веб-дизайна. Извлечена своими словами, без дословного копирования транскриптов.
- [`external-sites.md`](external-sites.md) — разбор отдельных плохих сайтов из мирового веба: Wayfair (потребительская площадка), Университет Луизианы (образовательный сайт), Neuro 2 (типичный нейросетевой дизайн).

## Связанные источники

- Скриншоты «плохо vs хорошо»: `../good-bad/`
- Скриншоты плохих сайтов целиком: `../good-bad/bad-sites/`

## Как этим пользоваться

При работе над любым дизайн-элементом (блок, форма, кнопка, секция) нейросеть и человек сверяются с этими материалами. Главный вопрос: «не совершаю ли я одну из задокументированных здесь ошибок?»

После сборки финального `docs/design/do-and-dont.md` материалы этой папки остаются как первоисточники.
