# Папка bad-sites — плохие сайты целиком как анти-референсы

В этой папке — скриншоты сайтов, чьё общее впечатление мы считаем плохим примером. В отличие от соседней папки `good-bad/`, здесь не пары «до/после», а отдельные сайты для общего понимания «как не надо».

## LadyClean (`ladyclean.png`, `ladyclean2.png`)

Сайт клининговой компании, сделанный партнёром через нейросеть «на коленке», без проработки дизайна. Конкретные проблемы:

- **Чёрный фон по всему сайту.** Создаёт ощущение гемблинг-площадки или сомнительной тематики, а не сервиса бытовых услуг. Чёрный фон без сильной концепции даёт ассоциации, не подходящие для клининга.
- **Уродливые градиенты на первом экране.** Перегружают восприятие, не работают на смысл.
- **Нет шапки сайта.** Пользователь не понимает, куда попал, нет навигации, нет логотипа на привычном месте, нет контактов под рукой.
- **Оффер теряется.** Цифра «64 рубля в час» прячется в общей композиции. Если цена — главный аргумент, она должна быть акцентом, а не растворённым элементом.
- **Космические анимации на hover кнопок.** Не вяжутся с темой бытового сервиса, выглядят как Star Wars / гемблинг / порно. Создают недоверие.

**Анти-правила, извлечённые отсюда:**

- Не использовать чёрный фон в качестве основного для сайта услуг доверительной категории (клининг, уборка, ремонт).
- Шапка с навигацией и контактами обязательна — это базовое ожидание пользователя.
- Главные цифры оффера (цена, скидка, срок) должны быть визуальным акцентом.
- Анимации должны соответствовать категории услуги; для бытового клининга — спокойные, минимальные.

## Avtodal (`avtodal.png`)

- Очень старый дизайн в чистом виде. Без современных стандартов отступов, типографики, контрастов.
- Хороший пример «как выглядит сайт начала 2010-х». Цель — отслеживать, чтобы наш сайт не имел признаков этой эпохи: устаревших шрифтов, шероховатой графики, перегруженных таблиц, неадаптивной вёрстки.

**Анти-правила:**

- Никаких визуальных артефактов «старого веба»: серых градиентов в кнопках, рамок-обводок с засечками, выровненного по центру длинного текста, табличной вёрстки на главных страницах.

## Tidy (`tidy.png`)

Сайт клининговой компании в Минске, сделанный шаблонно на Тильде.

- **Иконки никак не стилизованы.** Чёрного цвета, не вписаны в общую палитру, выглядят чужеродно.
- **Иконки непропорционально большие.** Нарушают визуальную иерархию — внимание уходит на них, а не на услугу или цену.
- **Белый текст на светлом фоне в карточках услуг.** Не читается. Базовая ошибка контраста.
- **Общее впечатление:** видно, что сайт собран быстро из готовых блоков Тильды без проработки. Это и есть тот эффект «шаблонности», которого мы хотим избежать.

**Анти-правила:**

- Иконки должны быть стилизованы под палитру сайта (наша палитра — синий / голубой / белый / чёрный).
- Размер иконок подчинён иерархии: иконка-маркер не должна быть крупнее заголовка или цены.
- Контраст текста на фоне проверять обязательно: минимум WCAG AA (соотношение 4.5:1 для основного текста).
- Не оставлять сайт в состоянии «собран из дефолтных шаблонных блоков». Каждый блок должен быть осмысленно подогнан под бренд.

## Что НЕ нужно делать с этой папкой

- Не использовать ни один из этих сайтов как референс «как сделать».
- Использовать только для тренировки распознавания анти-паттернов.
