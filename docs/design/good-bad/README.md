# Папка good-bad — визуальные референсы «плохо vs хорошо»

Эта папка содержит скриншоты, показывающие конкретные дизайн-приёмы и анти-приёмы. Используется как визуальный референс на этапе построения дизайн-документации.

Подпапка [`bad-sites/`](bad-sites/) — отдельные полностью «плохие» сайты целиком (для общего впечатления, не для конкретных приёмов).

## Пары «до / после» из видео-разборов

### Пара 1 (`youtube–baddesign1.png` / `youtube–gooddesign1.png`)

- **Источник:** видео «7 ошибок в веб-дизайне, которые кричат, что ты новичок».
- **Принципы, которые иллюстрирует пара:**
  - перегруженный визуал без иерархии («плохо») против чистого блока с единым акцентом («хорошо»);
  - дублирующиеся декоративные элементы (обводки, заливки) против сдержанного дизайна с явным акцентом.

### Пара 2 (`youtube–baddesign2.png` / `youtube–gooddesign2.png`)

- **Источник:** то же видео.
- **Принципы:**
  - хаотичная система отступов и скруглений против согласованного ритма;
  - иконки в разных стилях против иконок из одного набора.

### Пара 3 (`youtube3–baddesign1.png` / `youtube3–gooddesign1.png`)

- **Источник:** видео про маркетинговое мышление в интерфейсе.
- **Принципы:**
  - несколько одинаковых CTA-кнопок без приоритета («плохо») против одного главного CTA («хорошо»);
  - размытое позиционирование против явного, считываемого за 3–5 секунд.

### Пара 4 (`youtube3–baddesign2.png` / `youtube3–gooddesign2.png`)

- **Источник:** то же видео.
- **Принципы:**
  - перегруженный экран без визуальной иерархии против сфокусированного экрана с одной главной мыслью;
  - случайные подписи / иконки против системного использования размера и контраста для расстановки акцентов.

## Одиночные плохие сайты-референсы

### `Wayfair.png`

- **Принцип-урок:** отсутствие визуальной иерархии. Все элементы примерно одинакового размера и контраста — пользователь не понимает, на что смотреть в первую очередь. Парализует выбор.
- Подробнее: `../anti-references/external-sites.md`.

### `LOUISIANA.png`

- **Принцип-урок:** сложная раскрывающаяся навигация. Мелкий шрифт, плотные элементы, плохой контраст пунктов меню с фоном. Hover-эффект (затемнение всего столбца) раздражает.
- Подробнее: `../anti-references/external-sites.md`.

### `Neuro 2.png`

- **Принцип-урок:** «нейросетевой» дизайн — избыточные градиенты, яркие цвета, космическая стилистика. Узнаётся сразу, выглядит дёшево.
- Подробнее: `../anti-references/external-sites.md`.

## Что НЕ нужно делать с этой папкой

- Не удалять скриншоты.
- Не использовать «плохие» примеры как образец стиля при работе над сайтом Clean Logic.
- При работе над дизайном — открывать пару «плохо/хорошо», смотреть оба варианта, понимать различие, переносить «хороший» подход (не копировать дословно, а перенимать принцип).
