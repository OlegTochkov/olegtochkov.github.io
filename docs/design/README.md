# Дизайн-документация — Clean Logic

Это набор правил, по которым строится визуальный облик сайта. Цель — чтобы нейросеть и человек делали интерфейс предсказуемо хорошо, а не «средне-нейросетево».

Все значения (цвета, размеры, отступы) извлечены из реального рабочего CSS — `public/css/home.css` — и сверены со скриншотами. Это не выдуманная система, а формализация того, что уже нравится владельцу.

## Состав

- [`visual-identity.md`](visual-identity.md) (RU) — философия бренда, цветовая палитра, политика градиентов, роль фото/иконок.
- [`typography.md`](typography.md) (EN) — шрифт, размеры, веса, межстрочные интервалы.
- [`spacing-grid.md`](spacing-grid.md) (EN) — контейнер, сетка, отступы, брейкпоинты.
- [`components.md`](components.md) (EN) — кнопки, формы, карточки, шапка.
- [`motion.md`](motion.md) (EN) — переходы, hover-состояния, разрешённые анимации.
- [`do-and-dont.md`](do-and-dont.md) (RU) — свод «как надо / как нельзя», главный проверочный документ.

## Исходники

- [`screenshots/`](screenshots/) — скриншоты текущего сайта (главная, калькулятор, заказ).
- [`anti-references/`](anti-references/) — текстовые анти-правила из видео-разборов и плохих сайтов.
- [`good-bad/`](good-bad/) — визуальные пары «плохо vs хорошо».

## Язык документов

Гибрид: философия и своды правил (`visual-identity`, `do-and-dont`) — по-русски, потому что описывают бренд и читаются человеком. Чисто технические токены (`typography`, `spacing-grid`, `components`, `motion`) — по-английски, потому что это CSS-значения и термины.

## Главный принцип

Хороший дизайн — это **удаление лишнего, единая система и фокус на одном действии пользователя**. При любом сомнении сверяйся с [`do-and-dont.md`](do-and-dont.md).
