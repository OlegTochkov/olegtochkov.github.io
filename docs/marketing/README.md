# Маркетинговая документация — Clean Logic

Здесь собран маркетинговый контекст проекта: данные об аудитории, каналах, метриках, тоне коммуникации, конкурентах и результатах тестов. Эти документы используются нейросетью при написании текстов для сайта, принятии продуктовых решений и работе с конверсией.

## Состав

- [`metrics.md`](metrics.md) — текущие KPI, конверсия, стоимость лида, поведение на сайте.
- [`audience.md`](audience.md) — демография, сегменты, поведенческие паттерны, выводы из кампании.
- [`channels.md`](channels.md) — источники трафика, стоимость лида по каналам.
- [`tone-of-voice.md`](tone-of-voice.md) — правила обращения, запрещённые и рекомендованные формулировки.
- [`competitors.md`](competitors.md) — список конкурентов.
- [`experiments.md`](experiments.md) — история тестов и выводы.

## Ключевые инсайты — одним абзацем

Основная масса пользователей — женщины 25–34 и 55+, приходящие с телефона за ценой. 60–70% — «ценовые разведчики», которые не готовы оставлять контакты после холодного расчёта. Конверсия 1%, 1–2 заявки в неделю. Главная проблема — разрыв между ценой и воспринимаемой ценностью: клиент видит цифру, но не понимает, что за ней стоит. Калькулятор сейчас работает как инструмент отсева, а должен работать как инструмент конверсии. УТП пока не сформулировано.
