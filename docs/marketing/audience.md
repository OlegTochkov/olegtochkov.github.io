## Устройства

85% — смартфоны. **Сайт разрабатывается mobile-first.** Всё — от шрифтов до кнопок — оптимизируется сначала для телефона, потом для десктопа.

## Поведенческие паттерны

### Типичный путь пользователя

```
Реклама / Kufar → Сайт → Первый экран (цена) → Калькулятор → Цена → Уход
```

60–70% не планируют заказывать прямо сейчас — они пришли «узнать сколько».

### Что пользователь хочет знать

1. Сколько стоит.
2. Что конкретно входит.
3. Можно ли доверять (пустить чужих людей домой).

### Что мешает конверсии

- Цена воспринимается в отрыве от ценности — нет ответа «за что именно эти деньги».
- Не понятно, что именно сделают (нет страницы «что входит»).
- Нет управления ожиданиями → конфликты и недовольство после уборки.
- Нет ответа «почему именно вы».
- Повторные визиты (45 сессий) — есть интерес, нет доверия.

## Сегмент риска

Есть доля клиентов с завышенными ожиданиями («будет как новая квартира»). Реальность с ожиданием расходится → конфликты. Задача сайта — управлять ожиданиями заранее: страница «что входит / что не входит», честное описание результата.

## Портреты (не формализованы — нужно уточнить позже)

На основе данных можно предположить два основных портрета:

**Портрет 1 — «Занятая Алина, 28 лет»**
Работает, мало времени, ценит делегирование. Принимает решение быстро, по цене и простоте оформления заказа. Заходит с телефона, смотрит калькулятор, хочет «нажать одну кнопку». Боится, что придут незнакомые люди и что-то не понравится.

**Портрет 2 — «Татьяна Ивановна, 58 лет»**
Хочет помощи, но не уверена в «этих интернет-сервисах». Доверие строится через понятный язык, наличие телефона и реальных отзывов. Может позвонить вместо того чтобы оставить заявку онлайн. Важно, чтобы всё было прозрачно.

Уточнение портретов — отдельная задача (интервью с реальными клиентами).
