# История тестов — Clean Logic

Документация проведённых A/B-тестов, наблюдений и выводов. Обновлять при каждом новом тесте.

## Формат записи

```
### Тест: [название]
- Гипотеза: ...
- Что изменили: ...
- Результат: ...
- Вывод: ...
- Дата: ...
```

---

## Тест 1 — Повышение цен в калькуляторе

**Гипотеза:** повышение цены не сильно снизит конверсию — рынок не чувствителен к цене.

**Что изменили:** цены в калькуляторе стоимости подняли на 30–40%.

**Результат:** количество заявок снизилось (точный процент не зафиксирован).

**Вывод:** аудитория чувствительна к цене. Поднятие цены без параллельного увеличения воспринимаемой ценности напрямую снижает конверсию. Прежде чем поднимать цену — нужно сначала усилить аргументацию «за что».

**Статус:** завершён.

---

## Тест 2 — Фото в рекламном объявлении (Kufar)

**Гипотеза:** фото с человеком (девушка-сотрудница) даст больше кликов, чем фото без человека.

**Что изменили:** добавили фото девушки в промо-изображение объявления на Kufar.

**Результат:** CTR заметно вырос. Люди «тыкали» на объявление значительно активнее.

**Вывод:** реальный человек в рекламе вызывает больше доверия и внимания, чем абстрактное изображение (интерьер, логотип, паттерн). Подтверждает принцип «визуал как сигнал доверия».

**Применение:** использовать фото реальных сотрудников во всех рекламных материалах. Зафиксировано в `tone-of-voice.md`.

**Статус:** завершён.

---

## Наблюдение — Изменения на сайте снизили заявки

**Что произошло:** после внесения изменений на сайт количество заявок снизилось.

**Вывод:** любые изменения сайта нужно сопровождать мониторингом метрик (конверсия, количество заявок, поведение в Метрике). Нельзя вносить изменения и «забыть проверить».

**Правило для будущих правок:** после любого значимого изменения сайта — неделя наблюдения за метриками. Если конверсия упала — откатить.

## Что стоит протестировать (гипотезы)

Это идеи для будущих тестов. Каждый тест — отдельная итерация, одна переменная за раз.

| Гипотеза | Приоритет |
|---|---|
| Добавить «что входит в уборку» → вырастет конверсия среди price-check сегмента | Высокий |
| Добавить AI-комментарий в калькуляторе → снизит «холодный» выход после цены | Высокий |
| Показывать цену не сразу, а после 1–2 шагов прогрева | Средний |
| Тест двух CTA: «Рассчитать стоимость» vs «Узнать цену» | Средний |
| Страница «О нас» с фото команды → вырастет доверие и повторные конверсии | Средний |
| Добавить социальные доказательства (отзывы) на первый экран | Высокий |
