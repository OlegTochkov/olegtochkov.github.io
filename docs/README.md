# Документация проекта Clean Logic

Эта папка содержит всю проектную документацию: бизнес-контекст, технические решения, план миграции с Тильды, дизайн-систему, маркетинг, словарик терминов и описания удалённых Тильда-скриптов.

Навигационный индекс для нейросети — в корне проекта: [`../AGENTS.md`](../AGENTS.md).

## Принцип языкового разделения

Часть документов на русском, часть на английском — осознанно:

- **Русский** — для документов, которые читает человек и которые описывают русскоязычные реалии (бизнес, маркетинг, бренд, законодательство РБ).
- **Английский** — для технических документов и инструкций, где английский — родной язык предметной области, а нейросеть точнее работает с короткими императивными инструкциями.

## Кому это нужно

1. **Нейросети (Cursor)** — автоматически подгружать контекст через правила и `AGENTS.md`, не переспрашивать, работать в нужном направлении.
2. **Максиму** — не держать всё в голове, не забывать обоснования решений.
3. **Будущему покупателю сайта** — быстро разобраться, что досталось вместе с проектом.

## Принципы обновления

- Все важные решения фиксируются в документации, а не в голове.
- Решение поменялось — документация обновляется в тот же день.
- Документация — равноправная часть проекта.
- Перед удалением Тильда-скрипта обязательно создаётся файл в `docs/legacy/`.
- Не хватает контекста для задачи — расширяем документацию, а не угадываем.
